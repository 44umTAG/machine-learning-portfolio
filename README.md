# Machine Learning & Big Data Portfolio

В этом репозитории собраны учебные проекты по **Машинному обучению (Machine Learning)** и **Анализу больших данных (Big Data)**, выполненные в рамках обучения в колледже. 

Каждый проект представляет собой законченный pipeline: от сбора и очистки данных до построения моделей и создания полноценного приложения.

---

##  Структура репозитория и семестры

> **Важное примечание о нейминге:** 
> Исторически папки в репозитории названы по номерам семестров. В будущем планируется их переименование для большей прозрачности, но пока навигация выглядит следующим образом:

* 📁 **`1semestr`** — Проекты за **6 семестр** *(2-й семестр 3-го курса, весенний)*.
* 📁 **`2semestr`** — Проекты за **7 семестр** *(1-й семестр 4-го курса, осенний)*.

---

## Проекты

###  Movie Recommendation System 
**Статус:** Завершен | **Семестр:** 7 (Папка `2semestr`)

Полноценное приложение для рекомендации фильмов, включающее в себя исследование данных, обучение моделей и разработку бэкенда с интерфейсом.

#### Архитектура и структура проекта:

```text
2semestr/Movie_Recommendation_System/
│
├── 📁 api/             # Бэкенд и API
│   ├── init files      # Файлы инициализации
│   └── main.py         # Логика API, работающего с базой данных
│
├── 📁 app/             # Клиентская часть / Интерфейс
│   ├── images/         # Изображения и ассеты, используемые в приложении
│   └── app.py          # Главный .py файл с кодом интерфейса приложения
│
├── 📁 data/            # Исходные данные
│   └── README.md       # Описание датасетов, скачанных с Kaggle
│
├── 📁 database/        # База данных
│   └── ...             # Файлы БД, созданной на основе таблиц из `data`
│
├── 📁 notebooks/       # Исследование и ML-модели
│   └── research.ipynb  # EDA, очистка данных, обучение, оценка и создание моделей
│
├── 📦 data_archive.zip # Архив с исходными сырыми данными с Kaggle
├── 📊 popular_movies.csv         # Итоговая таблица популярных фильмов
├── 📊 similar_movies.csv         # Итоговая таблица похожих фильмов
└── 📊 user_recommendations.csv   # Итоговая таблица рекомендаций для пользователей
