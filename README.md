# machine-learning-portfolio
Проекты по машинному обучению и большим данным.

В папке 2semestr находятся проекты за 7 семестр или первый семестр четвертого курса (надо переименовать чтобы было яснее);
В папке 1semestr находятся проекты за 6 семестр или второй семетр третьего курса.

2semestr:
  Movie Recommendation System работа над приложением рекомендующим фильмы: 
    в папке api можно увидеть файлы инициализации и само апи приложения основанное на базе данных.
    в папке app можно увидеть папку с изображениями используемыми в приложении и самм файл .py с кодом приложения
    в папке data находятся скачанные с сайта Kaggle таблицы данных с README
    в папке database находится база данных созданная на основе данных таблиц
    в папке notebooks находится ноутбук с кодом исследования, очистки данных, обучения и оценки алгоритмов, а так же созданием моделей рекомендаций Weighted Rating, User-Based, Item-Based, Content-Based
Так же в папке проекта можно увидеть архив со скачанными с сайта данными, а так же таблицы с популярными фильмами, похожими фильмами, а так же рекомендациями юзеров
